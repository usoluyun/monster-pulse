# M2 · Monster 视图设计与实现

日期：2026-10-08。用户确认第三版后已实现原生视图；下方迭代记录保留设计过程，当前行为以本节为准。

## 当前使用

主窗口顶部「仪表 / Monster」同步切换窗口与 Dock；每次启动默认显示仪表，不恢复上次的 Monster 页。Monster 底部仅保留「刷新额度」和「设置…」，查看详细数据直接切换「仪表」，不额外放详情按钮。

设置面板底部「Monster 外观…」打开独立外观窗口：六种颜色（额度、代理地面、5h 外圈与周内圈）、角色大小 85–110%、动作强度 0–150%、播放律动及恢复默认外观。改动即时保存；恢复外观不会改变当前显示模式、代理或采样配置。外观面板使用固定示例数据作预览，可通过「预览代理开启」检查两种地面配色；该开关不修改系统代理。真实主窗口与 Dock 使用采样数据。

原生实现为 `MonsterModel.swift`（轮廓、面积计算、配置校验）和 `MonsterView.swift`（共用绘制、外观面板）。运行时最多 10 fps，不增加系统采样或额度查询频率；休眠时停止 Dock 动画定时器，主窗口被遮挡或关闭时不重绘主窗口。关闭动画、强度为零、隐藏 CPU / GPU 或系统启用降低动态效果时停止对应动作。

用户确认双完整环后已接入原生 Dock 与主窗口：外圈表示 5h 时间、内圈表示周时间，均从顶部中央顺时针增长，亮段表示已过比例。两圈的完整暗轨始终保留，时间未知不画亮段；主窗口在额度读数下显示两行时间比例和重置倒计时，到期显示等待刷新。时间来自实际窗口与墙钟，随现有采样刷新；进度路径缓存，不增加采样或动画定时器。

没有额度数据时使用中性身体和问号，没有周额度时不画太阳；旧快照显示「旧」。不同额度窗口按时长匹配（300 / 10080 分钟），不把其他窗口猜成 5h 或周额度。

## 额度映射（已采用）

用户确认的预览采用：角色白色面积表示 **5 小时剩余额度**，背景太阳表示 **周剩余额度**。当前未提供交换映射的选项。

## 视图切换

应用主界面顶部放「仪表 / Monster」切换，默认保持现有仪表。切换同时影响主界面与 Dock，每次启动默认显示仪表，不恢复上次的 Monster 页；外观与律动偏好保存到本机。Monster 页保留刷新与设置入口，切换到仪表查看准确数值、重置时间和异常说明。

## 角色白色面积

沿用仓库中的灰白「未定体」轮廓，不另造角色。剩余 100% 时身体全白，70% 时身体面积 70% 为白、30% 为灰蓝填充色；用过的部分从脚底向上增长。按角色轮廓的横截面积求分界线，不能直接把高度百分比当成面积百分比。眼睛保持可读，身体变形时白色与填充一起变形，避免视觉上的额度晃动。

填充色保持固定，不借用 CPU / GPU 的颜色；额度低不会改变角色的繁忙动作，以免把余额与系统负载混淆。重置时白色恢复，不额外播放庆祝动画。当前额度与太阳随新数据直接更新，未实现额度过渡动画。

## 背景太阳

太阳位于角色右侧的可见天空。周剩余 100% 在最高处，50% 在中间，0% 落入地平线；消耗时单向下降，重置时回升。位置表示剩余额度，**不表示周内时间、当地时间或距离重置的倒计时**。

太阳不循环走完整的日出—正午—日落弧线：弧线两端的相同高度容易对应不同额度。天空随太阳下降逐渐变暗，亮度只作辅助，太阳高度是主要判据。0% 时太阳完全落下，无数据时用独立未知状态，不能假装太阳已经落下。

## 系统负载动作

- CPU：整体上下律动，负载越高，幅度及节奏越明显。
- GPU：横向舒展、回收，负载越高，伸缩越明显；脚底作为伸缩支点。
- 两者同时高时叠加，但幅度封顶，不能使角色碰边、覆盖太阳或影响白色面积判断。
- 低负载保持极轻的呼吸或静止；未知值不映射成零。
- 设置关闭 CPU / GPU 显示时，对应动作也停止参与表达；内存与磁盘在本轮角色设计中仅保留在仪表及详情，不另加第三、第四种动作。
- 提供降低动态效果，停止动画时保留静态额度、太阳和精确数值。

具体幅度与频率是预览参数，实施时依据真实 43pt Dock 的辨识度与绘制成本调整，不当作已验证的性能结论。

## 两种构图

- 完整场景：角色较小，保留更完整的天空与地面，适合主窗口。
- 角色优先（建议）：角色更大，保留右侧太阳可见区，适合 Dock；主窗口和 Dock 可使用同一套状态映射，以不同尺寸调整构图。

## 实施验收

验证 100 / 70 / 50 / 15 / 0% 与未知、过期状态；单独高 CPU、单独高 GPU及两者同时高。实际从 Dock 启动，检查视图切换、重启后默认仪表、隐藏指标后的动作，以及真实 43pt 尺寸的可读性。性能独立实测，隐藏窗口或降低动态效果时不得继续无意义地高频绘制。


## 第二版 · 代理状态、繁忙可辨性与外观配置

以下为设计迭代记录，代理与负载视觉以第三版为准。

- 代理使用左上角独立代理灯：实心 P 为系统代理开启，空心 P 为关闭，问号为未知。太阳继续只表示周剩余额度，避免日月同时承担额度与代理两种含义。状态来源应是 `NetworkStatus.proxyEnabled`，不能使用代表应用探测代理的 `probeProxyEnabled` 冒充系统代理。系统开关不等于所有请求实际经过代理。
- CPU 除上下律动外增加静态拉高与头顶脉冲线；GPU 除横向伸缩外增加静态展开与侧边能量线。暂以 35%、70%、90% 为分级边界，分别显示一、二、三道标记；暂停动画仍保留姿态与标记。该设计用来区分负载等级，精确百分比仍看详情。
- 第一版动画不明显是预览幅度不足；尚未实测真实 Dock 动画的流畅度或性能限制，不能以网页预览推断 Dock 的能力。
- 外观配置包含剩余额度色（默认白）、已用额度色、CPU / GPU 繁忙色、角色大小 85–110%、动作强度 0–150%，以及动画开关。角色大小改变角色在图标内的占比，不改变 macOS Dock 的全局图标尺寸。眼睛依据身体颜色自动选明暗对比。
- 正式实施时设置变更应即时预览并保存，支持恢复默认；代理 / 未知状态的语义、额度比例方向不因主题改变。阈值、性能验收与小尺寸识别需要真机验证。
- 第二版仍仅为设计预览，未实现原生 Monster 界面。

## 第三版 · 地面状态与纯角色律动

- 按用户反馈移除代理圆灯、头顶脉冲线与侧边能量线，不再增加角色外部的负载标记。
- 系统代理状态由角色脚下整片地面的颜色表示：默认开启为低饱和青绿，关闭为暖棕，未知为中灰。开启与关闭颜色允许配置；太阳仍只表示周剩余额度，地面不随额度变化。系统代理数据来源沿用 `NetworkStatus.proxyEnabled`。
- CPU 保留上下律动与静态拉高，GPU 保留横向伸缩与静态展开；动画关闭时保留负载姿态。高负载识别只依靠角色本身，真实 Dock 小尺寸下的辨识度仍待实施时验证。
- 外观配置保留剩余额度色、已用额度色、角色大小、动作强度与动画开关；原 CPU / GPU 繁忙色替换为代理开启 / 关闭地面色。
- 第三版已实现为原生主窗口与 Dock，保留原有轮廓回声；代理圆灯与负载线条均未加入。


## 时间进度设计记录（双完整环已确认并实现）

影子填充方案已被用户否决，底边双段不再作为当前候选。用户更倾向沿边进度，并要求两个独立完整环。最新预览改为外圈表示 5h 时间、内圈表示周时间；两圈都是闭合的圆角环，从顶部中央顺时针增长。原有角色填充与太阳继续表示各自剩余额度。

圆角修正：主窗口与 Dock 统一使用图标边长 20% 的圆角。128 单位画布中，外圈中心线内缩 6.5、圆角半径 21.5，内圈内缩 12、半径 16，线宽 2.4；四角使用圆弧，两条环的笔画完整落在图标裁切范围内，避免先前贴边的方形路径被 Dock 圆角切掉。0% 只显示完整的暗轨，100% 显示完整亮环。原生绘制与主窗口使用同一套路径，夹具同时覆盖 43pt 与 128pt。

七星与太阳作为备选设计记录，目前用户更倾向双完整环：七颗星固定在天空，每颗对应窗口的一天；一颗静止小点位于当前窗口日的星星下方。周剩余额度由亮星数量表示，100% 为七颗全亮，70% 为四颗全亮、第五颗接近全亮，其余保留暗星；小数部分通过该颗星的亮度渐变表达。星星不闪烁、不过期消失，避免把周时间与周额度混为一项。5h 时间由太阳从左侧地平线升起、经高点后向右落下，以及天空的黎明 / 白昼 / 黄昏配色表示；这是额度窗口的相对时间，不是真实当地时刻。角色填充仍表示 5h 剩余额度，地面色仍表示系统代理。七星方案只保留为设计记录，不实现。

七星方案的窗口日从实际窗口起点算起，不对应周一至周日。只有可信的七天窗口才使用七颗星表示天数；其他窗口长度与缺失数据需明确标为不适用或未知。43pt 下暗星与当前日小点的辨认程度尚未通过原生 Dock 验证，主窗口保留准确天数、额度与倒计时。

时间值来自该窗口的 `resetsAt` 与 `windowDurationMins`，复用 `QuotaFormat.windowProgress` 的校验规则，不从剩余额度推算，也不以星期或当地日出时间代替。重置时间缺失或窗口长度不可信时，不画对应时间填充，主界面明确显示未知；已到期显示等待刷新，不能自行假定新额度已到账。

主窗口在现有数值下增加两行轻量时间信息：窗口时间已过百分比与重置倒计时。43pt Dock 只适合粗看时间进度；准确时间看主窗口，不承诺能从小图标读出分钟。交互预览和离屏夹具为固定示例数据，真实应用使用服务返回的重置时间。

## 启动与 Dock 菜单补充

用户要求启动默认进入仪表，因此不再恢复上次的 Monster 页。角色律动默认勾选；手动关闭后仍保存该偏好。Dock 右键菜单新增「显示模式 → 仪表 / Monster」与「播放角色律动」，勾选状态与主窗口、外观配置共用同一份设置。在仪表模式切换律动偏好只影响之后的 Monster 动作。

双环颜色独立配置，暗轨沿用各自颜色的低透明度，进度亮段保留外圈 72% / 内圈 52% 的透明度。恢复默认外观同时恢复双环颜色；旧版本保存的配置缺少环色时补齐默认值，保留原有配色、大小和律动偏好。
